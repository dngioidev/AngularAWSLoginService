💡 Understanding Token Refresh

Learn how AWS Cognito token refresh works

🔑 Access Tokens

Short-lived tokens (typically 1 hour) used to access AWS resources. These expire frequently and need to be refreshed.

🆔 ID Tokens

Contains user identity information and claims. Also short-lived and refreshed along with access tokens.

🔄 Refresh Tokens

Long-lived tokens (typically 30 days) used to obtain new access and ID tokens. These are securely stored and used automatically.

⚙️ Refresh Process

  • 1. System detects token expiry (or manual trigger)
  • 2. Sends refresh token to AWS Cognito
  • 3. Receives new access and ID tokens
  • 4. Updates localStorage with new tokens
  • 5. Application continues with new tokens
